# School Management System

A school management system built with Python.

I built this project to improve my Python skills by working on a larger program instead of only doing small exercises. The system currently manages students and teachers, with the data stored in JSON files.

This is version 3 of the project. I have been adding new features, fixing bugs, improving validation, and changing parts of the program as I learn.

## Features

### Student Management

* Add students to classes 1–10
* Remove students
* Show all students by class
* Search for students
* Update student information
* Change a student's name
* Move a student to another class
* Input validation
* JSON data storage

### Teacher Management

* Add teachers
* Remove teachers
* Show teachers and their subjects
* Search for teachers
* Assign subjects to teachers
* Assign teachers to multiple classes
* Prevent duplicate subjects
* Prevent duplicate classes
* Input validation
* JSON data storage

## Technologies

## How It Works

When the program starts, the user can choose between the student management system, teacher management system, or exit the program.

Student management provides options for adding, removing, searching, showing, and updating students.

Teacher management provides options for adding, removing, searching, and showing teachers, along with their subjects and assigned classes.

The information is stored in `students.json` and `teachers.json`, so the data can be loaded again when the program is run.

## How to Run

Clone the repository:

```bash
git clone <repository-url>
```

Open the project folder:

```bash
cd School-Management-System
```

Run the Python file:

```bash
python main.py
```

Replace `main.py` with the actual name of the Python file if it is different.
